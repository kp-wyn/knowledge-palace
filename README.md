# Knowledge Palace Method (KP-4+1) / 知识宫殿法

> A personal & organizational knowledge operating system that turns fragmented knowledge into reusable, mountable, evolvable skills.
>
> 一套个人与组织知识操作系统：把碎片化知识，蒸馏成可复用、可挂载、可进化的能力。

---

## What is Knowledge Palace Method? / 什么是知识宫殿法？

**Knowledge Palace Method (KP-4+1)** is a knowledge operating system for individuals and organizations. Using a "palace" as its organizing metaphor, it structures fragmented information, experience and methodology across four architectural layers — Foundation (采集), Structure (建模), Processing (提取激活), Regulation (调控) — driven by a cross-cutting Human-AI Collaboration layer (+1).

知识宫殿法（KP-4+1）是一套个人与组织知识操作系统。以建筑宫殿为隐喻，把碎片化知识按四层主体结构组织起来：

| Layer / 层级 | Core Task / 核心任务 |
|---|---|
| **01 Foundation 地基层** | Collect, encode, quality-gate (三验一密) / 采集、编码、质检 |
| **02 Structure 结构层** | Classify, model, mount skills (库-区-房-卡) / 分类、建模、挂载技能 |
| **03 Processing 加工层** | Extract, activate, transfer, distill into skills / 提取、激活、迁移、蒸馏技能 |
| **04 Regulation 调控层** | Daily/weekly/monthly audit, prune, evolve / 日周月审计、淘汰、进化 |
| **+1 Human-AI 人机协同** | AI executes, human decides and takes responsibility / AI做执行，人做决策 |

**Core belief / 核心信念:** Knowledge is not for storing — it's for using. The palace is a workshop, not a warehouse.
知识不是用来存的，是用来用的。宫殿不是仓库，是工作台。

---

## Six Immutable Principles / 六条宪法

1. **Metaphor uniqueness** — Only "palace" metaphor; no warehouse/brain/garden metaphors as architecture
2. **4+1 structure** — Four layers fixed; +1 cuts across all four, not a fifth layer
3. **kp- naming** — Mature methods packaged as `kp-` prefixed mountable skills
4. **Card 7 elements** — Every knowledge card has: one-line core, content, usage, conditions, failure notice, related cards, source ID
5. **Distillation first** — Output is skills + cards, not storage. Workshop, not warehouse.
6. **Compliance baseline** — All external output passes legal review; sensitive data desensitized

## Key Concepts / 核心概念

- **三验一密 (Three Checks One Curtain):** Sandbox (疑) / Landmark (真) / Poison Pill (错) / Curtain (密+规) — quality gate for all incoming knowledge
- **库-区-房-卡 (Library-Zone-Room-Card):** Four-level classification
- **四类卡片:** Knowledge Card (知识卡 KP-CARD-), Experience Card (经验卡 KP-EXP-), Principle Card (原则卡 KP-PRI-), Wrong-Idea Card (错误想法卡 KP-ERR-)
